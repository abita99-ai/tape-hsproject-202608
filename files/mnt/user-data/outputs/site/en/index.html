Read the structure, see the performance

Every tape is a stack of liner, adhesive and carrier. Once you know what each layer decides, all 18 TDS read in the same grammar.

Liner → conversion

Paper (PCK / glassine) suits die-cutting & flatbed work; film (PET / MOPP) suits rotary, low-particle processes. A double liner (WH / PV36) is for pre-fabrication.

Adhesive → what, how strong, how hot

Mostly acrylic. Tackified acrylic grips LSE (PP/PE) and rough surfaces; rubber-based suits places where hand-tearability and flexibility matter, like harnesses. Some high-performance acrylics (200MP) are not recommended for LSE.

Carrier → thickness, flexibility, stability

Nonwoven for conformability, film for precise gauge and heat, foam for gap-filling / stress relaxation / waterproofing. No carrier means a transfer tape.
